Sound Visualization Tool

Overview

This interactive sound visualization tool allows users to load an audio file and experience a real-time, dynamic 3D representation of the sound. Built with p5.js, the tool analyzes the audio’s frequency spectrum and translates it into an immersive visual display.

Features

  • Playback Controls

    • Play/Pause the track
    • Fast forward and rewind by 10 seconds
    • Progress slider to seek through the audio

  • Audio Adjustments

    • Change playback speed
    • Adjust volume levels
    • Modify stereo panning
    • Load custom audio files

  • Visualization Mode

    • Vertical bars that pulse and shift in color based on frequency energy
    • A floating sphere that reacts to bass frequencies
    • Hue-shifting colors that change dynamically with sound intensity

Experience

When visualization mode is active, UI elements hide, allowing users to experience an interactive, music-driven 3D environment where sound comes to life with motion and color.

This tool transforms music into art, making any audio file a visual spectacle.
